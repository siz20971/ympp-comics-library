===================================================
  YMPP Comics Library (포터블 만화책 라이브러리)
===================================================

[프로그램 특징]
1. 초경량 네이티브 실행: 별도의 설치 과정 없이 'YMPPComicsLibrary.exe' 단일 파일로 즉시 실행됩니다.
2. 완벽한 포터블 구조:
   - 지정한 만화책 라이브러리 폴더 내에 '.ymppCache' 폴더가 자동 생성됩니다.
   - 메타데이터(SQLite DB) 및 WebP 표지 캐시가 만화책 폴더와 항상 함께 보관되므로, 만화책 폴더를 다른 외장하드, USB, PC로 옮겨도 데이터가 보존됩니다.
   - 프로그램 실행 파일(YMPPComicsLibrary.exe)을 원하는 위치 어디로 이동시켜도 상대 경로 기반으로 정상 작동합니다.

[주요 사용법]
- 라이브러리 선택: 상단 바의 폴더 아이콘을 눌러 만화책(ZIP / CBZ)이 들어있는 폴더를 선택합니다.
- 탐색 & 입장: 폴더를 클릭하면 우측에 상세 정보 및 태그/별점이 표시되며, 더블클릭하면 해당 폴더로 진입합니다.
- 만화책 열기: 만화책 카드를 더블클릭하거나 우측 상세 패널의 '만화책 열기'를 클릭하여 외부 뷰어로 실행합니다.
- 컨텍스트 메뉴: 파일/폴더를 마우스 우클릭하여 즉시 열기, 별점 편집(0~5점), Windows 탐색기 위치 열기 등을 실행할 수 있습니다.
- 태그 관리 및 DB 재구축: 우측 상단 톱니바퀴(환경설정) 버튼을 눌러 태그 이름 수정/삭제, 사용자 지정 뷰어(.exe) 연결, DB 완전 재구축을 수행할 수 있습니다.
